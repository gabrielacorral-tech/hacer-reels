# Reels completo

Un solo skill para Claude Code: instala las herramientas, aprende tu estilo de 3 videos de referencia, edita tus grabaciones con storyboard previo, revisa cada corte y aprende de tus correcciones.

## Instalar
Abrí Claude Code dentro del repo `hacer-reels` (lo carga solo), o copiá esta carpeta a `~/.claude/skills/reels-completo`.

## Usar
1. `instalá las herramientas de edición`
2. `aprendé este estilo: <link 1> <link 2> <link 3>`
3. `configurá mi skill` (entrevista corta)
4. `editá este reel: <archivo en grabaciones/>`
5. Mirá el storyboard, aprobalo, recibí el reel en `exportes/`.
6. Corregí con: "Corregilo y modificá el skill para que no lo vuelva a hacer."

Usá material de otras personas solo para estudiar el estilo, y con permiso para incluirlo.
