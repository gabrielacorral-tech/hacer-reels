# Reels completo

Un solo skill para Claude Code: instala las herramientas, aprende tu estilo de 3 videos de referencia, edita tus grabaciones con storyboard previo, revisa cada corte y aprende de tus correcciones.

## Instalar
Abre Claude Code dentro del repo `hacer-reels` (lo carga solo), o copia esta carpeta a `~/.claude/skills/reels-completo`.

## Usar
1. `instala las herramientas de edición`
2. `aprende este estilo: <link 1> <link 2> <link 3>`
3. `configura mi skill` (entrevista corta)
4. `edita este reel: <archivo en grabaciones/>`
5. Mira el storyboard, apruébalo, recibe el reel en `exportes/`.
6. Corrige con: "Corrígelo y modifica el skill para que no lo vuelva a hacer."

Usa material de otras personas solo para estudiar el estilo, y con permiso para incluirlo.
